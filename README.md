## Контрольные вопросы

1. Что такое О-нотация (Big O) и зачем она нужна?

О-нотация - это математическая запись, описывающая асимптотическое поведение функции при стремлении аргумента к бесконечности.
О-нотация показывает, как быстро растёт время работы алгоритма при увеличении входных данных, отбрасывая константы и младшие члены.

2. Какая сложность у доступа к элементу массива по индексу? Почему?

Анализ сложности - это математический способ оценки эффективности алгоритма в зависимости от размера входных данных.
Два вида сложности:

- Временная сложность (Time Complexity) - сколько времени выполняется алгоритм
- Пространственная сложность (Space Complexity) - сколько памяти использует алгоритм

3. Какая сложность у бинарного поиска? Почему?

O(log n). Увеличивается медленно, при удвоении данных время растёт на константу.

4. Что означает сложность O(n log n)? Приведите пример алгоритма.

Линейно-логарифмическая или же эффективные сортировки. Пример: Быстрая сортировка, слияние.

5. Что такое амортизированный анализ? Приведите пример.

Это метод оценки средней стоимости одной операции в худшей последовательности операций, где редкие «дорогие» операции «размазываются» по множеству дешёвых.

Ключевое отличие от «среднего случая»: не делается никаких предположений о распределении входных данных — гарантия даётся для любой последовательности.

Пример — push в динамический массив

6. Какая сложность у двух вложенных циклов по n итераций каждый?

O(n²). Время растёт квадратично.

7. Какая сложность у рекурсивного вычисления чисел Фибоначчи?

O(2ⁿ).

8. Что такое шаблоны функций? Как их объявить и использовать?

Это «заготовка» функции, где тип параметризован. Компилятор генерирует конкретные версии под каждый использованный тип. 

Объявление: 
```
template <typename T>
```

9. Что такое шаблоны классов? Как их объявить и использовать?

То же, но для целого класса — параметризуется тип полей, параметров методов, возвращаемых значений.
```
Box<int>         bi(42);
Box<double>      bd(3.14);
Box<std::string> bs("hi");
```

10. В чём преимущество шаблонов перед перегрузкой функций?

Перегрузка требует писать отдельную реализацию для каждого типа, а шаблон — одна реализация для всех типов. Также шаблоны: не дублируют код, работают с любым типом, автоматически подхватит тип, если он поддерживает нужные операции, генерирует специализированный код под каждый тип.

11. Как указать, что шаблонный параметр - тип?

Пишется либо typename, либо class — эквивалентны.

12.Можно ли создать шаблон с несколькими параметрами типов?

Да, сколько угодно — и типов, и нетиповых значений.

13. Как провести экспериментальное измерение времени выполнения?

Используют `std::chrono::high_resolution_clock`. Важно: Измерять несколько раз и брать минимум; Не давать компилятору выкинуть код — использовать результат; Один и тот же размер входа, один и тот же режим сборки; Замерять только «горячую» часть, без ввода-вывода и аллокаций, если они не часть алгоритма.

14. Почему при измерении времени нужно выполнять операцию многократно?

Однократный замер шумный и часто короче разрешающей способности таймера.

15. Что важнее: сложность алгоритма или константа?

На малых `n` константа часто важнее. Пример: `O(n²)` сортировка вставками на массиве из 20 элементов быстрее `O(n log n)`, а у вставок — компактный цикл, дружелюбный к кешу. На больших `n` сложность побеждает всегда. При `n = 10⁶` никакая константа не спасёт `O(n²)` от `O(n log n)`.
